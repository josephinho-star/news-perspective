Windows 11 tries new shortcuts for Xbox gaming mode and search

2026-10-31 15:12

The latest Windows 11 Insider build adds some powerful new search features and quick settings while in Xbox mode. The Xbox shortcuts let you control things like Bluetooth, WiFi, and power settings without having to exit gaming mode.

The latest Windows Insider builds revamp search with filters, actions, and phone controls.

The latest Windows Insider builds revamp search with filters, actions, and phone controls.

The search improvements are quite comprehensive. You can now filter results for files, actions, or web results. You can also use the search box to perform actions like changing the screen brightness or volume, and even perform actions on a connected phone, including making calls. Results can also offer much more detail, like when a file was last modified and its author, or pull in charts for stock prices and weather forecasts. And you can train Windows 11 search by clicking inline thumbs-up or thumbs-down icons to help it improve over time.

For the full list of changes, check out Microsoft’s blog post. Beta Build 26220.9836 and Experimental Build 26340.9843 are both available now to Windows Insiders.
