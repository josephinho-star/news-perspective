Apple is adding face unlock to the iPhone Duo — without new hardware

2026-11-16 18:44

Apple is working on a face unlock feature for the iPhone Duo that uses the front-facing camera for authentication, and it’s already testing it with the new iOS 27.3 beta released today, as reported by MacRumors. Currently, the only way to unlock the iPhone Duo is by using Touch ID or entering a passcode, which might feel like a step back if you prefer face authentication using the Face ID feature available on other iPhones.

Apple is testing a new iPhone Duo feature that would use the front-facing camera to look at your face for authentication.

The iPhone Duo’s face unlock feature seemingly has a few caveats, however: it’s only available for the lock screen, you can only use your face for an unlock if you have used Touch ID or input a passcode within 45 minutes, and you can’t use the face authentication for Apple Pay purchases.

iOS 27.3 is set to launch publicly in December, Apple said last month, so should the feature make it to the full release, you may not have to wait too long for it to be officially available.
