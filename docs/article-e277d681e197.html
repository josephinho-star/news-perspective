OpenAI expands ChatGPT’s plugins with app-like interfaces and automations

2026-09-29 17:15

OpenAI isn’t only coming after productivity software with ChatGPT’s new Pages, Slides and Space features — the AI lab is now targeting any application that could work better when integrated with ChatGPT.

At the company’s Dev Day presentation on Tuesday, the AI company said it is now allowing developers to build their own app-like experiences within ChatGPT using plugin extensions.

OpenAI already supports plugins, which connect ChatGPT to everyday tools like Slack, SharePoint, Airtable and Google Drive, but the new plugin extensions will give apps a dedicated home in the ChatGPT sidebar.

Plus, developers will be able to build interactive panels that let users work with their tools while they’re chatting with ChatGPT. This experience can also include file viewers that support whatever file formats the developer’s product uses, the company notes.

In addition, OpenAI says it’s making it easier for developers to build plugins, and streamlining the discovery process for end users. Devs are getting a new Plugin Creator tool for building, and can submit them to the plugin directory via a redesigned flow that offers clearer feedback.

Meanwhile, the company says it has improved how plugins are ranked and recommended within its directory, as well as when they’re surfaced in conversations. When users choose a plugin to work with, they can approve its access needs individually as well.

In addition, ChatGPT Sites, the lightweight websites users can build with ChatGPT, can host these plugins, too. For example, this would let someone share their apps with colleagues, who can use it with their own connected data and permissions.

OpenAI also said it’s adding support for the proposed MCP Events specification, which would allow plugins to start automations based on events in a connected app. The company is also making automations easier to add and manage.
