Your spreadsheets and your operating system are both covered for $35

2026-10-30 09:01

TL;DR: This $34.97 Microsoft Office Professional 2021 and Windows 11 Pro bundle (reg. $418.99) combines security and multitasking tools with productivity apps.

A computer can have all the processing power in the world, but that won’t help much if you don’t have the software to get anything done. You still need something to run the machine and something to handle the spreadsheets, presentations, emails, and documents that somehow take up your entire workday. This Microsoft bundle covers both with Windows 11 Pro and Office Professional 2021, available together for a one-time payment of just $34.97 (reg. $418.99).

Windows 11 Pro takes care of the operating system side of things, with features that go beyond the basics. Snap layouts help organize open windows when you’re juggling multiple tasks, while BitLocker encryption adds protection for sensitive files.

If you like getting under the hood of your computer, Hyper-V lets you create virtual machines, and Windows Sandbox provides an isolated space for testing software. You also get support for compatible biometric sign-in hardware and DirectX 12 Ultimate for supported games and graphics cards.

Then there’s Microsoft Office Professional 2021, which includes the apps you’ve probably spent years using. Word handles documents, Excel takes care of spreadsheets, and PowerPoint helps you put together presentations that hopefully don’t require a million slides.

Outlook keeps email and calendars organized, while OneNote is useful for collecting notes and ideas. The package also includes Access, Publisher, and the free version of Teams.

Both licenses are intended for use on one Windows PC, and Office 2021 is tied to the device rather than your Microsoft account. Neither product requires a Microsoft 365 subscription. However, Microsoft ended support for Office 2021 on October 13, 2026, meaning the apps can still run but no longer receive security updates or technical support.

Before purchasing, check that your computer meets Windows 11’s hardware requirements using Microsoft’s PC Health Check app. This license won’t bypass compatibility restrictions, and eligible Windows 10 PCs may already qualify for a free Windows 11 upgrade.

Formerly $418.99, grab the Windows 11 Pro and Microsoft Office Professional 2021 lifetime license bundle for only $34.97.
